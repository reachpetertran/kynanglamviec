Reference frameworks

The site's 10-skill framework is built on published international frameworks, adapted to Vietnam and mapped to the core competencies of Vietnam's 2018 General Education Curriculum.

Framework names are used for reference only. All descriptions, "I can…" statements and lessons are written by this site. The site does not translate or adapt the content of any framework.

Levels

The site uses 5 levels: 1. Exploring → 2. Starting → 3. Secure → 4. Proficient → 5. Leading. For comparison: Australia's Core Skills for Work framework uses 5 stages from Novice to Expert; Singapore's SkillsFuture Critical Core Skills uses 3 levels: Basic, Intermediate, Advanced.
